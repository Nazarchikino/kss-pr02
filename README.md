# helpdesk-ts – стартовий проєкт до практичної роботи № 2

Освітній компонент «Розробка клієнт-серверних застосувань», розділ 1.

1. Встановіть залежності: `npm install` (TypeScript і типи Node.js – лише як devDependencies).
2. Прочитайте `SPEC.md`.
3. Виконуйте завдання за методичними вказівками; перевіряйте себе командою `npm run check`.

| Каталог / файл | Призначення |
|---|---|
| `src/` | ваш код TypeScript |
| `src/legacy/report.ts` | успадкований модуль, який треба привести до режиму `strict` |
| `dist/` | результат компіляції (створюється автоматично, до Git не додається) |
| `test/*.test.js` | тести поведінки – **не змінювати** |
| `typecheck/*.check.ts` | перевірки на рівні типів – **не змінювати** |
| `data/` | приклади даних у форматі JSON |

Потрібен Node.js 24 LTS або новіший.
